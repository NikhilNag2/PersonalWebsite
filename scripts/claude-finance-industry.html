💹 Claude Finance Agents — 3 Tools That Collapse the Retail vs Institutional Gap

💡 What This Is

Anthropic dropped a marketplace of 20+ finance plugins for Claude.

Most of them are built for banks, hedge funds, and PE firms. Four of them are built for you. This guide breaks down the four that matter for retail investors — what they do, how to use them, and what they won't do (the part no one tells you).

🎯 The Four Plugins That Matter

# Plugin Type Best For
01 📊 Equity Research Skill bundle · 15 commands All-in-one analyst workspace
02 🔍 Earnings Reviewer Agent · 6 commands One stock just reported — react fast
03 🧮 Financial Analysis Skill bundle · 18 commands DCFs, comps, model audits
04 🌐 Market Researcher Agent · 5 commands Sector views and idea generation
The other 15+ plugins are back-office accounting, sell-side banking, or compliance tools. Useful if you run a fund. Irrelevant if you run a portfolio.

🧮 03 — Financial Analysis


Tier 1 · Game-changer · Skill bundle · 18 commands


The math layer. DCFs, comps, three-statement models — everything you need once you've decided a company is worth modelling.


The clever part: the audit and debug commands. Paste in any model you built or downloaded and get every formula error, broken link, and inconsistent assumption flagged in seconds. That alone justifies the install.


📋 7 Retail-Relevant Commands
/dcf                → DCF valuation with comps-informed terminal multiples

/comps              → Comparable company analysis with trading multiples


/3-statement-model  → Income statement, balance sheet, cash flow from filings


/comps-analysis     → Deeper institutional-grade comps with operating metrics


/audit-xls          → Audits any spreadsheet for formula accuracy and errors


/debug-model        → Debugs a financial model for broken assumptions


/deck-refresh       → Updates a presentation with new numbers


	```</code></pre></div></details>


💬 Copy-Paste Prompt
Build me a DCF valuation for [COMPANY / TICKER].

Include:


  1. A base, bull, and bear case for revenue over 3–5 years
  2. Key assumptions for each case (growth rate, margins, exit multiple)
  3. An estimated fair value range per share
  4. The top 3 risks that could break the bull case
  5. Format it as a clean table I can copy into Excel


Use publicly available financials and be transparent about every assumption.


	```</code></pre></div></details>


⚠️ Honest Limit
Steepest learning curve of the four. DCF and three-statement modelling assume you understand what they are — but worth using even if you don't. Claude explains its assumptions as it goes, and you'll learn faster building one DCF than reading ten articles about them. Start with /audit-xls if you're new.

🚫 What These Agents Won't Do


Read this section twice. It's the part that protects you from the tools.


01 — They won't tell you what to buy
Run /dcf on TSLA and you'll get a fair-value range, not a recommendation. Run /earnings-analysis on META and you'll get a complete read of the quarter, not a position to take. The agents surface the inputs to a decision. Pulling the trigger is still your job — and it should be.


02 — Their data has a cutoff
Most plugins lean on Claude's knowledge plus whatever you paste in. If you ask about a stock without giving it a current transcript or filing, you may be working with months-old context. Rule of thumb: if the analysis cites a specific number, the analysis is only as fresh as the document you fed it. Always paste the actual filing or transcript.


03 — Garbage in, garbage out
A DCF is only as good as the assumptions you put in. If you use a 15% perpetual growth rate, you'll get a clean, professional, completely useless valuation. The skill that matters with these tools isn't prompting — it's knowing when an output looks plausible but is built on a bad input.


04 — They don't replace judgement
These agents reduce the time from question to first answer by 90%. They don't reduce the time you should spend on the decision. The temptation with any tool this fast is to use the speed to do more work. The right move: use the speed to do better work on fewer names. Read more, decide less, hold longer.
