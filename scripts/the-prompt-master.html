⚗️ Prompt Master — Generate Any Prompt Instantly Inside Claude

💡 What This Is

Prompt Master is a Claude Code skill (or installable tool) that generates high-quality, ready-to-use prompts for you — based on whatever outcome you want to achieve.

Instead of spending time crafting mega prompts manually outside of Claude, you run it internally, get the prompt back, and paste it wherever you need it.

🎯 What Problem It Solves

Without Prompt Master With Prompt Master
Write long prompts manually in Notion, Google Docs, or Notes Generate them inside Claude directly
Guess at what phrasing will get the best result Get a structured, tested prompt built for your goal
Rebuild prompts every time your use case changes Describe what you want → get the prompt instantly
Switch between tools to craft then copy prompts Stay in one workflow end-to-end
