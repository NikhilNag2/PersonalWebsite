🚀 The 3-Step Setup

1️⃣ Set Up Your Design System

When you first open Claude Design, Claude builds a design system for your brand by reading your existing files and assets. Your colours, typography, and components are then applied to every project automatically.

💡 Already have a design system?

Upload it directly inside Claude Design and it will be applied to all your projects automatically.

🆕 Don't have one yet?

Use Prompt 1 below to generate a complete design system from scratch.

2️⃣ Create a New Project

Every project automatically uses your brand's colours, fonts, and components — no reconfiguration needed.

You can add extra context by uploading:

  • 📸 Screenshots or images of existing designs
  • 🏆 Competitor products or visual inspiration
  • 📄 Documents (DOCX, PPTX, XLSX)
  • 💻 A link to your codebase

3️⃣ Start Building

Describe what you want → Claude builds it → you refine from there.

💡 Tips for Best Results

  • 🧱 Start simple, then build up — get the core layout right first, then add detail and interactions.
  • 🎯 Be specific in your feedback — "Tighten the spacing between form fields" beats "This doesn't look right."
  • 💬 Use inline comments for small changes — click directly on any element on the canvas.
  • 🗣️ Use chat for big changes — structural shifts, new sections, or aesthetic overhauls.
  • 🔀 Ask for variations — have Claude show you 2–3 options and compare.
  • 🧑‍🎨 Ask Claude for feedback — it can review for accessibility, contrast, and usability.

🎨 Prompt 1 — Generate a Complete Design System

📋 Click to expand prompt
You are a senior brand designer. I need you to create a complete, production-ready design system for my brand that I can upload into future Claude Design projects as the source of truth.

Brand Context


  • Business name: [YOUR BUSINESS NAME]
  • Industry: [YOUR INDUSTRY]
  • Target audience: [WHO THEY ARE + what they care about]
  • Brand personality (pick 3–5 adjectives): [e.g. modern, minimal, warm, trustworthy, playful]
  • Competitors I admire visually: [2–3 brands + what I like about each]
  • Competitors I want to look nothing like: [1–2 brands]
  • Preferred colours (or leave blank): [HEX codes or description]
  • Must-have accessibility standard: WCAG 2.2 AA minimum


Deliver a structured design system with:


  1. Colour palette — primary, secondary, accent, neutrals (9-step scale), and semantic colours (success, warning, error, info). Include HEX, RGB, and usage guidance for each.
  2. Typography scale — font pairings (heading + body), a modular type scale (H1–H6, body, small, caption), weights, and line heights.
  3. Spacing &amp; layout grid — 4px or 8px base unit, spacing scale, container widths, and responsive breakpoints.
  4. Component styles — buttons (primary, secondary, ghost, destructive + all states), cards, inputs, badges, modals, and navigation. Include hover, focus, active, and disabled states.
  5. Iconography &amp; illustration direction — style (line/filled/duotone), stroke width, and a mood board description.
  6. Motion principles — easing curves and duration tokens for micro-interactions.
  7. Do&#x27;s and don&#x27;ts — 5 of each, with visual examples where possible.


Format the output as a structured living style guide I can reference and upload into future projects. Flag any accessibility risks you spot in my colour choices.

What's new: senior-designer framing, competitor context (both positive and negative), accessibility standard baked in, full component states, motion tokens, and a requirement to flag risks.




📱 Prompt 2 — Design a Full App UI Flow


📋 Click to expand prompt
Using my uploaded design system, design the complete UI flow for my app. Treat this like you're shipping v1 — every screen should be pixel-ready, not a rough sketch.

App Overview


  • App name: [APP NAME]
  • One-sentence description: [WHAT IT DOES]
  • Core user goal: [THE JOB THE USER IS HIRING THIS APP TO DO]
  • Primary user persona: [WHO THEY ARE + context of use]
  • Platform: [Web / iOS / Android / All]
  • Emotional tone the app should evoke: [e.g. calm &amp; focused / energetic &amp; fun / premium &amp; serious]


Screens to Design (in order)


  1. Splash / Onboarding — 3-screen walkthrough that sells the core value prop before asking for anything.
  2. Sign up &amp; login — email + social, with password-less option and clear error states.
  3. Main dashboard / Home — the user&#x27;s first &quot;wow&quot; moment. Include empty state (first-time user) and populated state.
  4. [KEY FEATURE SCREEN] — [e.g. booking flow / product listing / analytics view]. Include loading, success, and error states.
  5. Profile &amp; settings — account, notifications, privacy, billing, and sign out.


For Each Screen Deliver


  • Layout structure with clear visual hierarchy
  • Every UI component used, tied back to my design system
  • Realistic copy (no Lorem Ipsum — write actual microcopy)
  • Accessibility notes (contrast, tap targets, screen reader labels)
  • State variations: default, hover, active, empty, loading, error
  • Micro-interactions worth calling out


Output Format


Show screens in user-flow order with annotations, then end with a &quot;design decisions&quot; summary explaining why you made the key calls you did.

What's new: ship-ready framing, emotional tone, user persona, realistic copy requirement, accessibility notes, full state coverage, and a design-decisions recap.




🎥 Prompt 3 — Animated Explainer Video


📋 Click to expand prompt
Create a 60-second animated explainer for [YOUR PRODUCT/CONCEPT] designed to convert cold viewers into interested leads.

Context


  • Product/concept: [WHAT IT IS]
  • Audience: [WHO IT&#x27;S FOR]
  • Single core message the viewer must walk away with: [ONE SENTENCE]
  • Call to action: [e.g. &quot;Start free trial&quot; / &quot;Book a demo&quot;]
  • Brand tone: [adjectives]


Structure (60 seconds, beat-by-beat)


  • 0:00–0:03 — Hook. Pattern interrupt or sharp question that stops the scroll.
  • 0:03–0:15 — Problem. Agitate the pain the viewer already feels.
  • 0:15–0:40 — Solution. Visualise how the product works using motion graphics and simple metaphors.
  • 0:40–0:52 — Proof. A stat, customer logo bar, or testimonial beat.
  • 0:52–1:00 — CTA. Clear, single action with visual emphasis.


Deliver


  1. Storyboard (frame-by-frame with timing)
  2. Voiceover script with pacing notes
  3. On-screen text and kinetic typography callouts
  4. Suggested music mood and sound design cues
  5. Motion principles (easing, duration) consistent with my design system


Keep it visual-first — if a beat works without the voiceover, it&#x27;s strong.


	```</code></pre></div></details>


What's new: beat-by-beat structure with timing, conversion framing, voiceover + on-screen text separation, sound design cues, and a "works without VO" quality bar.




💻 Prompt 4 — High-Converting Landing Page


📋 Click to expand prompt
Design a high-converting landing page for [PRODUCT NAME]. The single job of this page is to move visitors from cold traffic to [PRIMARY CTA — e.g. free trial signup, demo booking].

Context


  • Product: [ONE SENTENCE]
  • Primary audience: [WHO THEY ARE + what they care about]
  • Stage of awareness: [unaware / problem-aware / solution-aware / product-aware]
  • Competitors they&#x27;re comparing us to: [2–3]
  • Brand feel: [adjectives]
  • Primary CTA: [e.g. &quot;Start free trial&quot;]
  • Secondary CTA: [e.g. &quot;Watch 2-min demo&quot;]


Sections to Design


  1. Hero — headline (outcome-focused, not feature-focused), subheading, primary CTA, and a visual or product screenshot.
  2. Problem/agitation — 2–3 pain points the visitor is nodding along to.
  3. Solution / how it works — 3-step visual walkthrough.
  4. Features — 4–6 benefit-led feature cards (benefit in the headline, feature in the subtext).
  5. Social proof — customer logos, testimonials with names and roles, and at least one metric (e.g. &quot;2.4x faster onboarding&quot;).
  6. Pricing — 3 tiers with one marked as most popular; include annual/monthly toggle.
  7. FAQ — 5–7 questions that handle the top objections.
  8. Final CTA — restate the promise, single big button.


Design Requirements


  • Mobile-first responsive design
  • Above-the-fold must communicate value in under 5 seconds
  • Clear visual hierarchy — one dominant CTA per section
  • Accessibility: WCAG 2.2 AA, tap targets ≥44px, contrast ratios called out
  • Write real copy — no placeholders


End with a short conversion-rationale note explaining the key decisions (headline choice, CTA placement, pricing anchor).

What's new: awareness stage, primary + secondary CTAs, benefit-led feature cards, real metrics in social proof, pricing structure specifics, and a conversion-rationale recap.




📊 Prompt 5 — Investor-Ready Pitch Deck


📋 Click to expand prompt
Build an investor-ready pitch deck for my startup [STARTUP NAME]. Target a [PRE-SEED / SEED / SERIES A] round of [$AMOUNT]. The deck should be visual-first, scannable in under 3 minutes, and land the "why now, why us, why this" story.

Context


  • Startup: [ONE-SENTENCE DESCRIPTION]
  • Stage: [IDEA / BUILDING / LAUNCHED / REVENUE]
  • Monthly revenue or key traction metric: [NUMBER or &quot;pre-revenue&quot;]
  • What makes us uniquely positioned to win: [THE UNFAIR ADVANTAGE]
  • Brand colours: [HEX CODES]


Slide Sequence (12 slides max)


  1. Title — company name, one-line positioning, founder names, date.
  2. Problem — a specific, painful, universal problem. Use a story or stat, not bullets.
  3. Solution — what we built, in one visual.
  4. Why now — the shift in the world that makes this inevitable.
  5. Product demo — 2–3 screenshots with annotations showing the &quot;aha&quot; moment.
  6. Market size — TAM / SAM / SOM with a credible bottoms-up calculation.
  7. Business model — how we make money in one diagram.
  8. Traction — the strongest metric we have, visualised.
  9. Competition — 2×2 matrix or feature grid showing our wedge.
  10. Team — founders + key hires with the one sentence that makes each one credible.
  11. The ask — how much we&#x27;re raising, what we&#x27;ll do with it, milestones it unlocks.
  12. Contact / appendix — email, calendar link, and any backup data investors typically ask for.


Design Principles


  • One idea per slide. If a slide has two ideas, split it.
  • Max 10 words of body copy per slide — the rest is visual.
  • Consistent layout, typography, and colour usage across every slide.
  • Every chart must have a one-line takeaway callout.
  • Speaker notes underneath each slide (2–3 sentences of what the founder actually says).


End with a page on what to cut if we need a 10-slide version.

What's new: fundraising stage and amount, "why now" slide, bottoms-up market sizing, 2×2 competition matrix, speaker notes, and a cut-down version instruction.
