🚀 How to Install Any Skill (60 seconds)

1️⃣ Go to the GitHub repo

🔗 github.com/coreyhaines31/marketingskills — all 29 skills listed with descriptions.

2️⃣ Pick a skill and open it

Click the skill folder (e.g. content-strategy), then click the .md file inside. This is what Claude reads.

3️⃣ Download the raw file

Click the Download raw file icon near the top right of the file viewer. Saves the .md to your computer.

4️⃣ Upload to Claude

Claude desktop app → Customize (gear icon) → Skills → + → Upload a Skill → drag the .md in. Done.

🎯 Pro tip — bulk install: Download every .md you want first, then drag them all into Claude at once. All 29 in ~10 minutes. No conflicts.
🧠 Pro tip — prime Claude with your business first: Before using any skill, spend 2 minutes telling Claude what you sell, who your customers are, what makes you different, and your goals. Claude applies that context to every skill output. Generic vs. personalized results = a few sentences of context.
