I Built a Claude Skill That Predicts Viral Posts (200K Views Proof)

💡 I built a Claude skill that predicts exactly what you need to post to go viral. I ran it on my last post and pulled 200K+ views — and it did the same for my clients. This is the full breakdown of how it works and how you can build it yourself.

🎯 Overview

This skill scrapes the top-performing content in your niche, transcribes it, analyzes the visual format, and hands you a clean report of exactly what's working right now.

What You Get 📊

OutputWhat It Tells You
📝 Full transcriptsWord-for-word breakdown of every top post
👁️ Visual analysisHow each video is shot, edited, and structured
❤️ Like countRaw engagement signal
🪝 HookThe exact opening line that stopped the scroll
💬 Comment countConversation + algorithm fuel
📈 Outlier scoreHow far a post overperformed vs. the account's baseline
🎠 Format supportWorks for Reels AND Carousels
💡 The outlier score is the secret weapon — it surfaces posts that beat an account's normal performance, not just accounts that are already big.

🧩 How It Works — The 3-Phase System

Phase 1: Scrape & Rank 🔎

  1. The skill checks your saved competitor list — or you drop in a specific list of accounts you want to scrape.
  2. It calls Apify to pull the last week's worth of posts for each account.
  3. A Python script ranks every post and selects the top 3 per creator.

Phase 2: Fan Out Sub-Agents 🤖

  • Claude spins up multiple sub-agents in parallel.
  • Each sub-agent analyzes the visual format of a single video.
  • It also pulls the full transcript.
💡 Fanning out sub-agents is what makes this fast. Instead of analyzing one video at a time, Claude handles them all at once.

Phase 3: Orchestrate & Report 📄

  • Once the sub-agents finish, the main orchestrator agent gathers all the data.
  • It writes up a clean HTML report with everything in one place — transcripts, hooks, scores, and visual notes.

⚙️ Step-by-Step Setup

<details><summary>🛠️ Full setup walkthrough</summary>

  1. Build your competitor list — Collect the handles of 5–15 accounts crushing it in your niche.
  2. Connect Apify — Set up an Apify account and grab your API token for the scraper actor.
  3. Configure the Claude skill — Point the skill at your competitor list and Apify connection.
  4. Set the scrape window — Default is the last 7 days; adjust as needed.
  5. Set ranking rules — Tune the Python ranking logic (likes, comments, outlier score weighting).
  6. Enable sub-agent fan-out — Allow Claude to dispatch parallel analysis agents.
  7. Choose your output — HTML report is cleanest, but you can export to Markdown too.
  8. Run it — Trigger the skill and let all three phases execute end to end.

</details>

🔎 Phase 1 — Scrape & Rank Prompt

You are a content research orchestrator.

INPUT: A list of competitor account handles in my niche.

TASK:
1. For each account, call the Apify scraper to retrieve all posts
   from the last 7 days (Reels and Carousels).
2. For each post, capture: post URL, type (Reel/Carousel),
   like count, comment count, posted date, and caption.
3. Calculate an OUTLIER SCORE for each post = post engagement
   divided by that account's median engagement over the window.
4. Rank posts per creator by outlier score.
5. Return the TOP 3 posts per creator as a structured list.

OUTPUT: A clean table grouped by creator, sorted by outlier score.

🤖 Phase 2 — Sub-Agent Analysis Prompt

You are a single-video analysis sub-agent.

INPUT: One post (URL + type).

TASK:
1. Pull the full transcript of the video.
2. Identify the HOOK (the first spoken or on-screen line).
3. Analyze the VISUAL FORMAT:
   - Shot type (talking head, b-roll, screen recording, text-on-screen)
   - Editing pace and pattern
   - Text/caption styling
   - For Carousels: slide count, layout, and narrative flow
4. Note the content structure (problem → solution, listicle,
   story, demo, etc.).

OUTPUT: A compact analysis object with transcript, hook,
visual notes, and structure label.

📄 Phase 3 — Orchestrator Report Prompt

You are the main orchestrator agent.

INPUT: All sub-agent analysis objects.

TASK:
1. Merge every analysis into one dataset.
2. Surface the patterns: most common hooks, dominant formats,
   recurring structures across top performers.
3. Generate 3-5 actionable recommendations for what I should
   post next, based directly on the data.
4. Render everything as a clean, well-structured HTML report
   with sections, tables, and the raw transcripts in collapsible
   blocks.

OUTPUT: A single HTML report file.

💡 Pro Tips

<details><summary>🎯 Tip 1 — Curate your competitor list ruthlessly</summary>

Don't just add the biggest accounts. Add accounts at your size that occasionally blow up. Their outliers are far more replicable than a mega-account's baseline.

</details>

<details><summary>📈 Tip 2 — Trust the outlier score over raw likes</summary>

A post with 50K likes on an account that averages 500K underperformed. A post with 20K likes on an account that averages 2K is a goldmine. Always sort by outlier score first.

</details>

<details><summary>🪝 Tip 3 — Study hooks as a group</summary>

When you see the same hook structure across multiple top performers, that's a proven pattern. Build your next post around the shared formula, not a single example.

</details>

<details><summary>⚡ Tip 4 — Re-run weekly</summary>

Trends move fast. A weekly scrape keeps your recommendations fresh and catches new formats before your niche saturates them.

</details>
