🔑 Claude Secret Codes — 100 Prompt Shortcuts

🔑 100 prompt shortcuts organized by category. Each code changes how Claude responds by forcing a specific mode, format, or reasoning pattern. Type the code and Claude switches into that mode.

🔗 Source → mavgpt.ai

📌 At a Glance

🔢 Total codes 100
📦 Categories 10
🎯 How to use Type the code at the start of your prompt
🔄 Stackable Yes — combine codes (e.g. /deepthink • /layered)
📱 Works on Any Claude plan, any interface
💡 How codes work: Codes in /lowercase slash format trigger a mode. Codes in ALLCAPS act more like commands or personas. Both work the same way — drop them into your prompt and Claude shifts into that mode for the response.
